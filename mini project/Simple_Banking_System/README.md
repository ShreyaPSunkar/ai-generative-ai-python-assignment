# Simple Banking System

## About the Project

The Simple Banking System is a basic Python project that performs common banking operations such as checking balance, depositing money and withdrawing money.

## Features

- Account details
- Check balance
- Deposit money
- Withdraw money
- Basic input validation
- Menu-based operation

## Technologies Used

- Python
- Functions
- Conditions
- Loops
- Modules

## Files

- `banking_system.py` - Main program
- `bank_utils.py` - Functions used by the banking system

## How to Run

Run the following command:

python banking_system.py

## Sample Operations

The user can check the balance, deposit money, withdraw money and view account details through the menu.
